# Website design defaults

Use the approved Form & Field Editorial Dark foundation. Read [redesign 1311.md](<redesign 1311.md>), [DESIGN.md](DESIGN.md), and [the original kit guide](docs/editorial-dark-DESIGN.md). This is the default for future MCP website builds unless the user supplies another brand or requests another design. Preserve established designs in unrelated products and original catalog specimens.

Start UI builds with find-design-system and retrieve the actual selected kit. Load get-ui-principle before styling and get-ux-principle before behavior. Preserve routes, visitor drafts, error recovery, source licenses and existing working changes. Before delivery, run get-review-rules, review-ui-code, check-comprehension and inspect-spacing on rendered DOM; fix critical and serious findings. Follow the required dashboard review workflow for dashboards.
