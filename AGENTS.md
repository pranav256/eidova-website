# Website design defaults

Use the clean modern Neutral foundation in [redesign 1311.md](<redesign 1311.md>) and [DESIGN.md](DESIGN.md). The user rejected the earlier Editorial default. Select the actual minimal-light React/Radix kit, Inter typography and light appearance by default, preserving explicit visitor appearance choices. This also applies to future MCP website builds unless another brand is supplied. Keep unrelated products and original specimens faithful to their own systems.

Start UI builds with find-design-system and retrieve the actual selected kit. Load get-ui-principle before styling and get-ux-principle before behavior. Preserve routes, drafts, error recovery, licenses and existing working changes. Before delivery run get-review-rules, review-ui-code, check-comprehension and inspect-spacing on rendered DOM, fixing critical and serious findings. Follow the dashboard review workflow for dashboards.
